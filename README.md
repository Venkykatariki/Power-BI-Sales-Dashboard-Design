# Power BI Sales Dashboard

## ✅ Task Overview
As part of the Data Analyst Simple Sales Dashboard Design**. The goal was to build an interactive sales dashboard that provides insights into sales performance by product category, region, and over time.

## 💼 Tools Used
- **Power BI** for data visualization  
- **Superstore_Sales.csv** dataset  

## 📊 What I Did
- Imported the sales dataset into Power BI
- Transformed the **Order Date** field into **Month-Year** format
- Created the following visuals:
  - 📈 **Line Chart**: Sales trends over months
  - 📊 **Bar Chart**: Sales distribution across different regions
  - 🍩 **Donut Chart**: Sales contribution by product category
- Added a **Slicer** to filter visuals by Region
- Used color formatting to highlight top-performing categories and regions
- Generated insights based on the dashboard data

## 📌 Key Insights
1. **West region** had the highest overall sales in Q3.
2. **Technology category** generated the most profit.
3. **Sales peaked** in December, indicating strong holiday performance.
